# Style Guide Compliance Check

Read the style guide: `brand/style_guide.md`

Then audit the specified file or project for brand compliance: $ARGUMENTS

## Checks

1. **Colors** — scan all CSS/HTML for color values:
   - Brand background color present
   - Brand accent color used for highlights
   - Brand CTA color used for CTAs only
   - Brand positive color used for wins only
   - White for text
   - NO yellow, NO pastel, NO neon green, NO bright red
   - Max 2 accent colors per composition

2. **Typography** — check font declarations:
   - Montserrat required (or Inter/Poppins/Manrope as backup)
   - Correct weights: 900/800 for headlines, 700 for CTAs, 600 for captions
   - No Comic Sans, Papyrus, script fonts, ultra-thin fonts
   - No italic for emphasis

3. **Text Content** — check on-screen text:
   - No em dashes or hyphens as punctuation
   - Brand name spelled in full (never abbreviated in customer-facing text)
   - All caps for stat callouts
   - Title case for headlines
   - Sentence case for captions

4. **Pacing** — check timing:
   - Hook in first 3 seconds
   - No talking head shot longer than 5-6 seconds
   - B-roll shots 2-4 seconds each
   - CTA present at end

5. **Prohibited Elements** — flag any:
   - Generic stock footage
   - Yellow karaoke captions
   - Lens flare overuse
   - Cheap zoom/shake transitions
   - Fake countdown timers
   - "As seen on" logos

## Output

Produce a pass/fail checklist with specific line numbers and fixes needed for any violations.
