# Brand Logos

This directory holds your brand logo files. Logo files are excluded from git via `.gitignore`.

## Setup

Place your logo PNG files here. The overlay templates and agents reference logos from this location.

## Recommended Formats

- **PNG with transparency** — Primary format for video overlays
- **SVG** — Vector format for scalable usage

## Recommended Sizes

| Variant | Width | Use Case |
|---------|-------|----------|
| Standard | 500px | Lower-third overlays, watermarks |
| Wide | 1000px | Intro/outro cards, full-width placements |

## Naming Convention

```
logo-standard.png
logo-wide.png
```
