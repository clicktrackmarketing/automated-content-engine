# Reference Edits

This directory holds reference editing materials that teach the agents how to replicate a specific visual editing style.

## Contents

| File / Directory | Purpose |
|-----------------|---------|
| `editing-style-guide.md` | Structural analysis of a high-performing Reel, documenting visual editing patterns |
| `frames/` | (Excluded from repo) Reference frame screenshots |

## How to Create Your Own Reference Edit Analysis

1. **Find a high-performing video in your niche.** Look for Reels, TikToks, or Shorts with strong engagement. Choose a video whose editing style matches the energy you want.

2. **Screenshot every 2 seconds.** Capture a frame approximately every 2 seconds to build a visual timeline.

3. **Place screenshots in `frames/`.** Name them sequentially (e.g., `frame_001.jpg`, `frame_002.jpg`).

4. **Document the visual patterns.** For each segment, note:
   - Visual mode (talking head, split-screen, screen mockup, kinetic typography, etc.)
   - Caption style and placement
   - Transition type (hard cut, zoom, swipe)
   - Pacing (seconds per segment)
   - Recurring patterns or motifs

5. **Use the patterns in your agents.** The agents read `editing-style-guide.md` to understand your preferred visual rhythm. The more specific your analysis, the better the replication.
